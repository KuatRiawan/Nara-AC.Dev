## 2. Analisis Kebutuhan Nonfungsional (*Non-Functional Requirements*)

| Dimensi Kebutuhan | Kriteria dan Spesifikasi Kebutuhan | Mekanisme Realisasi di Sistem | Status Bukti |
| :--- | :--- | :--- | :---: |
| **NFR-01: Keamanan (Security)** | Kata sandi wajib di-hash menggunakan algoritma adaptif kuat; proteksi terhadap IDOR, XSS, dan CSRF. | Penggunaan `bcryptjs` (salt rounds 10), middleware JWT dengan cookie httpOnly, double-submit cookie CSRF, Helmet CSP, serta pemeriksaan kepemilikan IDOR pada seluruh endpoint data sensitif. | **Terverifikasi** (Lulus audit `Scenario G`) |
| **NFR-02: Privasi Data (Privacy)** | Nomor telepon tidak boleh terekspos utuh kepada publik; data mentah CSV tidak boleh memuat nomor telepon pelanggan. | Penyensoran nomor telepon pada tampilan publik (`0812****8843`), pembatasan unmasking hanya saat otentikasi valid, dan tokenisasi PII pada folder data science `data/governed/`. | **Terverifikasi** (Audit `Scenario G & H`) |
| **NFR-03: Integritas Transaksi (Data Integrity)** | Operasi multi-tabel (seperti penugasan teknisi dan penyelesaian pekerjaan) tidak boleh mengalami inkonsistensi parsial. | Pembungkusan kueri basis data mutasi dalam transaksi eksplisit `BEGIN ... COMMIT / ROLLBACK` menggunakan PostgreSQL pool client. | **Terverifikasi** (Uji Transaksi Backend) |
| **NFR-04: Kinerja Respon (Performance)** | Waktu respon rata-rata endpoint API backend harus berada di bawah 200 ms pada beban normal. | Paging kueri basis data SQL berindeks, payload JSON terkompresi, dan isolasi komputasi AI pada microservice Python terpisah. | **Terverifikasi** (Health latency < 25ms) |
| **NFR-05: Aksesibilitas & Responsivitas (UI/UX)** | Antarmuka web harus beradaptasi mulus dari layar smartphone (360px) hingga layar desktop (1920px); dukungan aksesibilitas WCAG. | Desain antarmuka fleksibel berbasis Tailwind CSS 4, dialog modal dengan focus trap, kontras warna Trust Blue standar, dan pemenuhan uji axe-core `jest-axe`. | **Terverifikasi** (11/11 Vitest Suites PASS) |
| **NFR-06: Keandalan & Ketahanan (Reliability)** | Layanan tidak boleh mengalami *single point of failure* jika microservice AI mengalami gangguan sementara. | Penerapan mekanisme fallback `ml_compat.py` pada AI Service, serta penanganan *try-catch graceful degradation* pada backend Express. | **Terverifikasi** (Uji Isolasi Backend) |
| **NFR-07: Batasan Beban (Rate Limiting)** | Mencegah serangan brute-force dan *denial of service* (DoS) pada antarmuka publik dan endpoint autentikasi. | Implementasi `express-rate-limit` dengan kuota 200 permintaan per menit per IP address, dengan jendela pemantauan terpisah untuk endpoint `/auth`. | **Terverifikasi** (`backend/src/app.js`) |
| **NFR-08: Kemudahan Pemeliharaan (Maintainability)**| Kode sumber harus bersih dari kode sampah, memiliki pemisahan tanggung jawab modular, dan struktur teratur. | Arsitektur rute terpisah (`routes/`), logika domain pada layer layanan (`services/`), migrasi basis data bernomor terurut, dan berkas konfigurasi terpusat. | **Terverifikasi** (39/39 JS Syntax Check PASS) |
